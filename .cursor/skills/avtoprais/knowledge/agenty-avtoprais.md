# АГЕНТ-СБОРЩИК (Hub) — ЦЕНТР ВСЕГО

## Что делает
- Собирает лиды со ВСЕХ площадок и каналов
- Стандартизирует данные в единый формат
- Отправляет в одно место (CRM / Google Sheets / Telegram)
- Уведомляет руководителя о срочных

## Откуда собирает
| Источник | Как | Что собирает |
|----------|-----|--------------|
| Авито API | Автопарсинг | Объявления по фильтрам |
| Авто.ру API | Автопарсинг | Объявления, цены |
| Дром API | Автопарсинг | Объявления, регионы |
| Telegram-бот | Клиент пишет | Фото, описание, телефон |
| WhatsApp | Клиент пишет | Текст, фото, локация |
| Email | Парсинг писем | Запросы, фото, документы |
| Форма сайта | Webhook | Параметры, контакты |
| Телефония | API | Запись, номер, длительность |
| Instagram/VK | API | Комментарии, Direct |

## Куда отправляет
- **Google Sheets** — единая таблица для быстрого доступа
- **CRM (Битрикс24/amoCRM)** — карточки сделок
- **Telegram-уведомление** — мгновенное оповещение менеджеру
- **Email** — детальный отчёт

# 14 СПЕЦИАЛИЗИРОВАННЫХ АГЕНТОВ

## 1. 📞 АГЕНТ-РАСПРЕДЕЛИТЕЛЬ ЛИДОВ

**Задача:** Куда отправить лид, кто будет работать

**Что делает:**
- Получает лид от Сборщика
- Определяет тип: выкуп / продажа / трейд-ин / комиссия / под заказ
- Смотрит загрузку менеджеров (кто свободен)
- Распределяет по правилам:
  - Выкуп → байеру (по региону / по смене)
  - Продажа → менеджеру (по загрузке)
  - Trade-in → байер + менеджер (пара)
  - Под заказ → агенту "Под заказ"
- Ставит задачу в CRM с дедлайном
- Если менеджер не взял за 15 мин — перекидывает другому
- Если никто не взял за 30 мин — уведомляет руководителя

**Куда отправляет:** CRM-задача + Telegram менеджеру

---

## 2. 🔍 АГЕНТ-ПРОВЕРЯЛЬЩИК АВТО

**Задача:** Проверить авто по базам ДО звонка клиенту

**Что делает:**
- Получает VIN от Сборщика
- Гонит через API:
  - Автокод (история, ДТП, пробег)
  - Автотека (доп. проверка)
  - ГИБДД (ограничения, штрафы)
  - ФНП (залоги)
  - РСА (страховки, ДТП)
- Формирует сводку:
  - 🟢 ЧИСТО — можно звонить
  - 🟡 ВНИМАНИЕ — есть нюансы (уточнить)
  - 🔴 ОПАСНО — арест, залог, перебитый VIN
- Если 🔴 — сразу уведомляет руководителя
- Прикрепляет отчёт к карточке в CRM

**Куда отправляет:** CRM-карточка авто + Telegram байеру

**Экономия:** Байер не тратит время на грязные авто

---

## 3. 💰 АГЕНТ-ОЦЕНЩИК

**Задача:** Посчитать выкупную цену до разговора с клиентом

**Что делает:**
- Получает параметры авто от Сборщика
- Лезет в Fishblue / Авто.ру / Авито — сравнивает цены продажи
- Считает:
  ```
  Рыночная цена продажи (средняя по аналогам)
  − Ремонт и подготовка (5-10%)
  − Маржа салона (15-25%)
  − Риски и залёг (5-10%)
  = МАКСИМАЛЬНАЯ ВЫКУПНАЯ ЦЕНА
  ```
- Добавляет диапазон для торга:
  - Первое предложение: −10% от максимальной
  - Цель: максимальная
  - Потолок: +5% (если авто очень ликвидное)
- Отправляет байеру: "Вилка 650-750 тыс, цель 720"

**Куда отправляет:** CRM + Telegram байеру

**Экономия:** Байер не гадает, а торгуется с цифрами

---

## 4. 📊 АГЕНТ-АНАЛИТИК РЫНКА

**Задача:** Знать рынок лучше конкурентов

**Что делает:**
- Мониторит цены на Авито/Авто.ру/Дром каждые 4 часа
- Отслеживает по 50-100 моделям (ваши ходовые)
- Считает:
  - Средняя цена продажи
  - Динамика (подорожало/подешевело за неделю)
  - Количество предложений
  - Средний срок продажи
- Делает прогноз:
  - "Camry 2020 — цена растёт, покупать сейчас"
  - "Solaris 2019 — перенасыщение, продавать быстрее"
- Отправляет отчёт руководителю каждое утро в 8:00

**Формат отчёта:**
```
📈 РЫНОК НА 15.08.2026

🔥 Растут в цене:
Toyota Camry 2020: +3.2% (ср. цена 1.85 млн)
Kia K5 2021: +2.1% (ср. цена 2.1 млн)

📉 Падают в цене:
Hyundai Solaris 2019: −1.8% (ср. цена 890 тыс)
Lada Vesta 2020: −2.5% (ср. цена 750 тыс)

⚠️ Перенасыщение:
Kia Rio 2018-2019 — 340 предложений в Москве
Рекомендация: не выкупать, продавать сток оптом

💡 Возможности:
BMW X5 2021 — мало предложений, цена стабильна
Рекомендация: активно искать на выкуп
```

**Куда отправляет:** Email + Telegram руководителю

---

## 5. 📢 АГЕНТ-РАСКИДЫВАТЕЛЬ ОБЪЯВЛЕНИЙ

**Задача:** Публиковать авто на все площадки одним кликом

**Что делает:**
- Сканит CRM: авто со статусом "В продаже"
- Генерирует описание:
  - Шаблон + уникализация (чтобы не банили за дубли)
  - Только факты, без воды
  - Пробег, владельцы, что сделано
  - Почему продаёт салон (не клиент)
- Заливает фото:
  - 12-15 штук
  - Обработанные (яркость, контраст)
  - Водяной знак салона
- Публикует:
  - Авито
  - Авто.ру
  - Дром
  - Юла
  - Telegram-канал
- Обновляет:
  - Цены если поменялись в CRM
  - Статус если продано
- Снимает объявления если:
  - Продано
  - Забронировано
  - Резерв

**Куда отправляет:** Площадки + отчёт в CRM

**Экономия:** Менеджер не сидит и не заливает фото вручную

## 6. 💬 АГЕНТ-ОТВЕТЧИК НА ОТЗЫВЫ

**Задача:** Не потерять репутацию

**Что делает:**
- Мониторит отзывы каждые 2 часа:
  - Google Maps
  - Яндекс.Карты
  - 2ГИС
  - Авито (отзывы о салоне)
  - VK
- Классифицирует:
  - ⭐⭐⭐⭐⭐ — положительный
  - ⭐⭐⭐ — нейтральный
  - ⭐⭐ — негативный
- Отвечает:
  - Положительные: "Спасибо! Расскажите друзьям — скидка 10 тыс"
  - Нейтральные: "Спасибо за отзыв. Что могли бы улучшить?"
  - Негативные: СРАЗУ уведомляет руководителя + черновик ответа
- Считает:
  - Средний рейтинг по площадкам
  - NPS
  - Динамика (лучше/хуже чем месяц назад)

**Куда отправляет:** Площадки + отчёт руководителю

## 7. 📝 АГЕНТ-БУХГАЛТЕР (выкуп)

**Задача:** Учёт без бумажек

**Что делает:**
- Получает данные сделки из CRM (статус "Оплачено")
- Формирует документы:
  - Договор КП
  - Акт приёма-передачи
  - Счёт-фактура
  - Справка-счёт
- Считает налоги:
  - НДС (если продажа юр. лицу)
  - УСН / ОСН
  - Налог на прибыль
- Ведёт журналы:
  - Выкупленные авто (по датам)
  - Проданные авто (по датам)
  - Маржа по каждому авто
  - Оборот по месяцам
- Контролирует:
  - Кто не заплатил
  - Кого не сняли с учёта
  - Просроченные задачи
- Отправляет бухгалтеру:
  - Пакет документов на каждую сделку
  - Сводку по неделе/месяцу

**Куда отправляет:** 1С / Google Sheets / Email бухгалтеру

## 8. 🔔 АГЕНТ-НАПОМИНАЛКА

**Задача:** Чтобы ничего не забыли

**Что делает:**
- **Менеджеру:** "Перезвонить Иванову через 2 часа"
- **Байеру:** "Авто на складе 25 дней — пора продавать"
- **Клиенту:** "Ваше авто готово к выдаче"
- **Руководителю:** "5 сделок без движения > 3 дней"
- **Бухгалтеру:** "3 авто не сняты с учёта — дедлайн завтра"
- **Клиенту (под заказ):** "Нашли 3 варианта, проверьте"

**Каналы:** Telegram / WhatsApp / SMS / Email

**Правила:**
- Не спамить — максимум 3 уведомления в день на человека
- Срочные — сразу
- Несрочные — сводка в 9:00 и 18:00

## 9. 🎯 АГЕНТ-ПОД ЗАКАЗ

**Задача:** Найти авто мечты клиента

**Что делает:**
- Получает заказ из CRM (параметры, бюджет, срок)
- Мониторит Авито/Авто.ру/Дром каждые 2 часа
- Отбирает по критериям:
  - Марка/модель/год
  - Пробег не более заявленного
  - Цена в бюджете
  - Регион (если указан)
  - Статус: не битый, не такси, не в залоге
- Формирует подборку:
  - 3-5 вариантов
  - Фото, цена, ссылка
  - Мини-отчёт: пробег, владельцы, состояние
- Отправляет клиенту:
  - Красивое сообщение с карточками
  - Кнопка "Хочу посмотреть"
  - Кнопка "Не подходит, ищем дальше"
- Если нашёл идеальный — сразу:
  - "🚨 СРОЧНО: Нашли ваше авто! До конца дня может уйти"
  - Фото, цена, почему идеально

**Куда отправляет:** Telegram/WhatsApp клиенту + CRM

## 10. 📈 АГЕНТ-КОНТРОЛЁР KPI

**Задача:** Руководитель всё видит

**Что делает:**
- Каждый вечер в 19:00 считает:
  - Кто сколько выкупил
  - Кто сколько продал
  - Средняя маржа по каждому
  - Конверсия: звонки → встречи → сделки
  - Старый сток (что продавать оптом)
- Сравнивает план/факт
- Выявляет:
  - Лидеров (похвалить)
  - Аутсайдеров (разобраться)
  - Проблемные авто (долго стоят)
- Отправляет руководителю:
  ```
  📊 СВОДКА ЗА 15.08.2026

  💰 ВЫКУП:
  Иванов: 3 авто, маржа 450 тыс (средняя 150 тыс) ⭐
  Петров: 1 авто, маржа 80 тыс ⚠️
  Сидоров: 0 авто 🔴

  🚗 ПРОДАЖИ:
  Иванов: 2 авто, выручка 3.2 млн
  Петров: 1 авто, выручка 1.8 млн

  📦 СКЛАД:
  Всего: 23 авто
  > 30 дней: 5 авто (рекомендация: продать оптом)
  > 45 дней: 2 авто (СРОЧНО продать)

  🎯 ПЛАН/ФАКТ:
  План выкупа: 20 авто/мес | Факт: 12 | Осталось: 8
  План продаж: 15 авто/мес | Факт: 10 | Осталось: 5
  ```

**Куда отправляет:** Telegram + Email руководителю

## 13. 🛡️ АГЕНТ-БЕЗОПАСНИК

  - 🚨 — срочно разобраться
  - 🟡 — проверить
  - 🟢 — всё ок

  - Оплата 100% предоплата
  - Передача документов
  - Вывоз авто

**Куда отправляет:** Оптовики + отчёт в CRM
