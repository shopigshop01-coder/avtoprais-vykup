## Что выкупаем

Любое состояние: битые, кредитные, в залоге, праворульные, Япония/Корея/Европа.
Также по текстам салона: мотоциклы, квадроциклы, катера, гидроциклы, яхты. Привоз с аукционов Японии, Кореи, Китая.
У крупных дилеров (ТТС) часто **не берут**: без ПТС, с убитой геометрией кузова после тяжёлого ДТП. Для АвтоПрайс уточнять политику, не обещать «всё подряд».
Обещания клиенту: выезд, расчёт в день сделки, оценка за минуты.
Ориентир сервиса как у ТТС: заявка → осмотр → документы → деньги **за ~4 часа**.

## Цена выкупа (правило салона)

1. Рынок Иркутска: Авито, Дром, Авто.ру, Юла.
2. **Выкуп = рынок минус 10–15%** (быстрый выкуп / запас на предпродажку и риск).
3. На сайте в калькуляторе сейчас **минус 10%**.
4. Если авто проблемное (ДТП, окрасы, кредит, ограничения) — запас больше, объясняй почему.

## Три типа байера (Haraba)

1. **Быстрый выкупщик** — первый звонок по объявлениям ниже рынка. Скорость важнее «идеальной» цены.
2. **Кладоискатель** — ведёт всех в CRM, сильный торг, встреча в салоне.
3. **Альтернативщик** — обратный выкуп / рекомендации, почти без классифайдов.

Для АвтоПрайса база — **срочный выкуп + входящие с сайта/бота**. Дальше: выезд, трейд-ин, комиссия.

## Модели выкупа (обучение 15.08.2026)

Не путать модели. Для АвтоПрайса **сейчас ядро — срочный выкуп**. Остальное — по очереди, не всё сразу.

| Модель | Маржа | Капитал / риски | Скорость | Запуск |
|---|---|---|---|---|
| Трейд-ин | 15–25% | средний / средние | быстрая | лёгкий |
| Срочный выкуп | 20–30% | средний / высокие | быстрая | средний |
| Выездной выкуп | 20–25% | средний / средние | быстрая | средний |
| Комиссия | 5–15% | низкий / низкие | медленная | лёгкий |
| Битые/проблемные | 30–50% | высокий / высокие | медленная | сложный |
| Кредитные | 15–20% | средний / высокие | средняя | сложный |
| Аренда с выкупом | 20–40% | высокий / средние | медленная | средний |
| Онлайн-выкуп | 15–20% | высокий / средние | быстрая | сложный |
| Telegram/YouTube | 10–20% | низкий / низкие | средняя | лёгкий |

Как работает коротко:
- **Трейд-ин** — старое в зачёт нового/БУ, клиент доплачивает. Драйвер продаж склада.
- **Срочный выкуп** — деньги за 2–3 часа, без покупки взамен. Цена ниже рынка ~20–30%.
- **Выезд** — байер к клиенту. У сетей даёт до ~30% склада. Цену лучше утверждает не байер, а прайсинг.
- **Комиссия** — авто клиента в салоне, комиссия 5–15%, капитал почти не нужен.
- **Битые** — выкуп дёшево → ремонт/разбор → продажа. Нужны СТО и юрист.
- **Кредитные** — погашение банку, остаток клиенту. Сложная юридика.
- **Аренда с выкупом** — не ядро салона, отдельный продукт.
- **Онлайн** — оценка по фото (как на сайте). Финал только после осмотра.
- **TG/YouTube** — лиды без Авито, аудиторию копить.

Очередь внедрения для АвтоПрайс:
1. Срочный выкуп (уже есть)
2. Выезд + онлайн-заявка с сайта
3. Комиссия (если не хотим рисковать капиталом)
4. Трейд-ин (если есть склад на обмен)
5. Telegram как канал заявок
6. Битые/кредитные — только с юристом и СТО
7. Авто под заказ — когда склад не закрывает запрос клиента

## Авто под заказ (курс, не ядро салона)

Клиент заказывает марку/год/бюджет — салон ищет и привозит. Это **не срочный выкуп**.
Срок обычно 1–4 недели. Предоплата **10–30%**. Маржа курса 10–20% + комиссия за подбор — для АвтоПрайс цифры не обещать, пока нет своего прайса.
Полный регламент: `knowledge/zakaz_avtosalon_polny.md` (часть 2).

## Чек-лист сделки (чтобы не обманули)

До осмотра: объявление, фото, VIN, пробег vs год, сколько дней висит, не «обнулёнка» Авито.
На осмотре: документы, VIN, толщиномер, OBD, следы ДТП/окраса, комплектность.
Базы: ГИБДД, ограничения, залоги, ДТП, такси/каршеринг, Автотека.
Юрлицо продавца: ФНС/ЕГРЮЛ при необходимости.
Не называть финальную цену до проверки.

## Скрипт звонка (коротко)

1. Представиться: АвтоПрайс Иркутск, выкуп.
2. Авто: марка, год, пробег, город, документы, кредит/залог.
3. Когда продаёт и почему (срочно / торг / уже есть покупатель).
4. Не торговаться вслепую. Предложить осмотр / заявку на оценку.
5. Сначала предложить **приехать в салон**. Отказ → выезд байера.
6. Если «уже продано / задаток» — не давить, оставить контакт на buyback.

Реакция на заявку — **до 15 минут**.
Ошибка дилеров: звонить на 10–15 день «обновлённого» объявления. Смотреть реальную дату.

## Выездной выкуп (как строить)

Не замена салону — **доп. охват** (у сетей до ~30% склада).

Роли:
1. Колл-центр — все лиды, сначала салон, иначе выезд.
2. Выездной байер = байер + диагност (толщиномер, OBD). GPS на авто.
3. **Прайсинг утверждает цену**, байер не сам.
4. Бухгалтерия закрывает сделку быстро (регламент + права в 1С).

Мотивация байера (кейс сетей): оклад + шт. принятых + доля **старого стока** на конец месяца (чтобы не забивать склад хламом).
Брать «с улицы» перекупа сложнее, чем вырастить своего.

Цифры чужих сетей — ориентир, не план АвтоПрайс: Carmart 16 выездных, ~1000 авто/год выездом; Автосеть.РФ ~150 авто/мес с выезда.

## Комиссия (регламент)

Клиент оставляет авто, деньги **после продажи**. Комиссия салона **3–15%**. Капитал на закуп: **0 ₽**. Срок продажи обычно 2–6 недель.

Шаги: договорённость и документы (ПТС оригинал, паспорт, 2 ключа) → снятие с учёта (часто) → осмотр/дефекты → опционально предпродажка → договор комиссии (сумма клиенту, %, срок 1–2 мес, неустойка, хранение) → фото и площадки → продажа и выплата.

Для АвтоПрайс: комиссия — если не хотим выкупать (неликвид / мало денег на складе).
Кейс ТТС: месяц на Авито без результата → комиссия салона → продажа за дни/2 недели **по цене клиента**.

## Сделка «как у ТТС» (~4 часа)

| Этап | Время | Что |
|---|---|---|
| Заявка | 5–10 мин | сайт / звонок |
| Осмотр | 30–60 мин | выезд оценщика |
| Документы | ~2 ч | ДКП, акт, снятие с учёта |
| Оплата | ~60 мин | карта или нал |

Оценка: ЛКП/салон/колёса → базы → диагностика → статистика рынка → озвучить цену.
Предпродажка (химчистка, полировка) **после выкупа**, на цену клиенту не влияет (модель Петровский).
РОЛЬФ: цену после осмотра **фиксируют в договоре**, не снижают «на месте».

## Кто за что отвечает (мини-штат)

Пока мало людей — роли можно совмещать, но **не смешивать цену и приём заявки**.

1. Менеджер выкупа — звонок, консультация, запись на осмотр.
2. Оценщик (выезд) — осмотр, фото/видео, диагностика.
3. Руководитель / хозяин / прайсинг — **финальная цена**.
4. Комиссия — отдельный менеджер, если пойдёт поток.
5. Юрист — ДКП, базы, снятие с учёта.
6. Бухгалтерия — выплата. Агент: навык `buhgalter-avtoprais` (скажи «бухгалтер АвтоПрайс»).

## Куда девать выкупленное

- Крупные (ТТС, РОЛЬФ): себе на площадку + гарантия + трейд-ин. **Не опт перекупам.**
- CarPrice: аукцион дилеров 25–30 мин, сами авто не держат, комиссию платит покупатель.
- Мелкий салон: часть розница, часть опт/закрытый TG, чтобы не заморозить деньги.
Для АвтоПрайс по умолчанию: **розница в Иркутске**. Опт — только если авто зависло.

## Чтобы салон работал без хозяина

- CRM: заявки, статусы, кто звонил, результат. Не дублировать в 3 системы.
- Регламент: скрипт → осмотр → проверка → **цена от прайсинга** → сделка.
- KPI: звонок ≤15 мин, % осмотров, % выкупов, маржа, доля старого стока.
- Отчёт хозяину: сделки дня, отказники, авто на складе.
